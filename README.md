# PUG REVERSI ｜ パグパグ オセロ大作戦！

「遊んで、集めて、育てて、世界一のパグマスターへ！」

かわいいパグたちと遊ぶ、スマートフォン向けのオセロ × コレクション × 育成ゲームです。
オセロで遊んでパグを集め、育てて、自分だけのお庭をつくり、大会でパグ王をめざします。

- **バージョン**：v1.0.0（全8段階 完了）
- **技術**：React 19 / TypeScript / Vite / SVG / Web Worker / Web Audio API / IndexedDB / Service Worker（PWA）
- **動作**：iPhone Safari・Android Chrome・PC のブラウザ。通信なしで遊べます（外部 API なし）

---

## 遊び方

1. ホームの「ひとりであそぶ」で CPU（EASY / NORMAL / HARD）と対局、「ふたりであそぶ」で1台の端末で対戦
2. 対局でコイン・経験値・パグポイントがもらえ、条件を満たすと新しいパグが仲間になります
3. 図鑑・着せ替え・育成・お庭・チャレンジ・パグカップ・ミッション・実績 で、毎日少しずつ遊べます
4. iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android はホームの「追加」ボタンで、アプリのように遊べます

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（例：`pug-reversi`。公開設定は Public）
2. このフォルダの中身を push する
   ```bash
   git remote add origin https://github.com/<あなたのユーザー名>/pug-reversi.git
   git push -u origin main
   ```
   （zip から始める場合は、展開したフォルダで `git init -b main && git add -A && git commit -m "PUG REVERSI v1.0.0"` を先に実行）
3. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
4. **Actions** タブで「Deploy to GitHub Pages」が緑になれば完成。`https://<あなたのユーザー名>.github.io/pug-reversi/` で遊べます
5. 以降は push するたびに、テスト → ビルド → 公開 が自動で行われます。新しい版はアプリに「新しいバージョンがあります［更新］」と表示されます

## 開発

```bash
npm install
npm run dev        # 開発サーバー（スマホから見るときは npm run dev -- --host）
npm test           # ユニットテスト（117件）
npm run build      # dist/ に本番ビルド（sw.js も自動生成）
npm run preview    # ビルドしたものを確認
# 総合テスト（ブラウザ）：preview を起動した状態で
pip install playwright && python3 e2e/e2e.py
```

## フォルダ構成

```
src/
├─ core/            ゲームロジック（React 非依存・テスト対象）
│   ├─ othello.ts     ルール・盤面・対局状態
│   ├─ ai.ts          CPU 3段階（ai.worker.ts で別スレッド実行）
│   ├─ progress.ts    対局結果の記録・報酬・パグ/アイテムの解放・育成・お店
│   ├─ garden.ts      お庭の配置判定・購入・拡張・パグの行動
│   ├─ modes.ts       チャレンジ判定・大会の進行・ミッション・ログインボーナス
│   └─ achievements.ts 実績の判定・戦績の集計
├─ data/            データ（パグ52種・アイテム・家具・ステージ・大会・ミッション・実績・数値）
│                   → キャラや実績を足すときは、ここに1行足すだけ
├─ store/           セーブデータ（IndexedDB・バージョン・マイグレーション）・設定・バックアップ
├─ services/        効果音・BGM・CPU 呼び出し・PWA・オンライン（将来用の独立した層）
├─ pwa/             Service Worker の生成（ビルド時）
├─ components/      パグの SVG（毛色・表情・帽子・アクセ）・盤面・お庭の絵・グラフ・演出
└─ screens/         各画面（ホーム・対局・図鑑・着せ替え・育成・お庭・チャレンジ・大会・ミッション・実績・プロフィール・戦績・設定）
tests/              ユニットテスト（Vitest）
e2e/                総合テスト（Playwright）
scripts/            詰めオセロ盤面の生成（完全読み）
public/             アイコン・起動画面・マニフェスト
```

## セーブデータ

- IndexedDB に保存（使えない環境は localStorage）。データ形式のバージョンは v5
- 形式を変えるときは `src/store/save.ts` の `SAVE_VERSION` を上げて `MIGRATIONS` に変換を足す（v1→v5 まで自動で引き継げることをテスト済み）
- 壊れたデータ・不正な値は、起動時に安全な値に直して読み込む
